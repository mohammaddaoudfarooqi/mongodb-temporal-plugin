# Quickstarts

| | What you get | Time | Needs |
|---|---|---|---|
| [`docker/`](docker) | Everything on your machine: MongoDB 8.2 with full-text and vector search, Temporal with the MongoDB plugin, the Temporal UI and the showcase | about 2 minutes | Docker |
| [`aws/`](aws) | Atlas M10 peered with an EC2 host on AWS, running Temporal, the showcase and the UI | about 15 minutes | An Atlas project and an AWS account |

Both run the [showcase](../examples/showcase), a support desk that uses
Temporal's durable workflows on MongoDB and the same cluster's search.
`tour` walks through every feature and checks it.
